CYBERSECURITY LAB SET UP

PROJECT OVERVIEW
-The project focuses on setting up a virtual lab using virtual box and Kali Linux.
-The lab for Kali Linux is configured on a private virtual network (NAT NETWORK WALKS) so that additional machines can be added and later used for targets for authorised security tests.
-The purpose of the lab is to create a controlled environment where cybersecurity tools,network scanning,vulnerability assessment and other security testing activities can be performed safely and repeatedly.

OBJECTIVES
-Install and configure virtual  box
-Install/import Kali Linux as a virtual machine
-Configured network connectivity for Kali linux
- Assign a consistent IP address for Kali Linux
- Verify network connectivity and DNS resolution
- Take a clean virtual machine snapshot for backup.
- Document the whole setup process
- Prepare the cybersecurity lab for future projects
